# Проверка качества цифрового издания «За пределами языка»

Цель: проверять работоспособность интерактива и мобильной компоновки перед каждым обновлением издания.

## Автоматические тесты

В папке `tests` находятся Playwright-тесты. Проверяются 11 разделов, каталог, поисковый индекс, 20 терминов словаря, сравнение двух моделей, семь этапов обучения, сценарные объяснения, закладки и отсутствие горизонтального переполнения. GitHub Actions запускает Chromium для настольного и мобильного профилей при изменении файлов проекта.

Локально из каталога `itmo-llm-2026`:

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

## Редакторские критерии

- Все цифры и статусы моделей должны указывать источник и дату публикации; не создавать рейтинг без сопоставимых независимых измерений.
- Интерактивная модель доли языка показывает сценарий, а не предсказывает реальное качество LLM.
- Корректно различать выводы отчёта ИТМО, редакционные интерпретации и гипотезы.
- Не смешивать художественные изображения и научные диаграммы без подписи.
- Для публикации в социальных сетях проверять Open Graph-предпросмотр.
- Поиск работает локально в браузере; запросы не передаются во внешнюю систему.
- Сохранённое место чтения записывается только в localStorage на устройстве читателя.

## Аналитика — ожидает подключения системы

Никаких внешних счетчиков поведения не подключено. Для дальнейшей настройки рекомендуются только агрегированные события: `open_search`, `search_result_click`, `model_filter`, `compare_models`, `stage_next`, `source_open`, `share_click`. Не записывать текст поисковых запросов, содержание пользовательских документов, идентификаторы посетителей без оснований и согласования.

## Ручной контроль перед релизом

1. Мобильные ширины 360, 390, 430 px; планшет 768 px; компьютер 1440 px.
2. Проверить скролл, видимость меню и кнопок, фокус клавиатуры, Esc, масштабирование текста до 200%.
3. Проверить в браузере загрузку всех изображений и PDF, в том числе при медленном соединении.
4. Прогнать Lighthouse на реальном опубликованном URL, измерить LCP, INP и CLS. Не выдавать оценку за измеренную до запуска теста.
5. Провести 5–8 качественных читательских сессий с разным уровнем понимания LLM.

Приоритет: сначала регрессии и источники, затем эксперименты и декоративные анимации.
